# QA — отчёты шагов

Отчёт шага с экраном: `docs/qa/<step>.md`. Имя файла — имя шага без префикса: `feat/search-screen` → `docs/qa/search-screen.md`. В отчёте вердикт и что именно проверили. Скриншоты в git не класть.

Для шагов без экрана (`docs/sdd-skeleton`, `chore/tooling`, `chore/husky`, функции запроса, `test/request-race`, `docs/design`) отчёт не нужен. Их проверка — `npm test`, `npm run lint` и чтение диффа.

Минимум для шага с экраном:

- сценарий из спеки этого шага проходит в браузере кликами, не одним скриншотом;
- соседний уже сделанный сценарий не сломан;
- в исходном `<body>` по-прежнему только `script`;
- в коде шага нет `innerHTML` и `insertAdjacentHTML`.

Страницу открывать после `npm run build` через локальный статический сервер. Модули с `file://` не проверять.

Перед сдачей отдельно пройти край из [ui.md](../specs/ui.md): пустой ввод, загрузка, быстрый набор и отмена в Network, 404, ошибка сети с «Повторить», клик по карточке.
