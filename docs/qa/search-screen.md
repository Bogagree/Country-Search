# QA: search screen

Проверено в браузере после `npm run build`.

- Пустой ввод очищает список и не показывает «Загрузка…».
- Непустой ввод показывает «Загрузка…», пока запрос не завершился.
- Успех рисует карточки: флаг, название, столица, регион, население.
- Пустой результат показывает «ничего не найдено» без оформления ошибки.
- Ошибка показывает «Не удалось загрузить страны» и кнопку «Повторить». Повтор отправляет последний введённый текст.
- Состояния загрузки, пустого результата, ошибки и списка различаются цветом и текстом.
