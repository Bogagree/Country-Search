# Country Search

Документация: https://github.com/rolling-scopes-school/tasks/blob/master/fullstack-engineering/tasks/country-search/README.md

Живой поиск стран по имени через `GET https://countries.dev/name/{query}` (без ключа, с CORS). Пользователь печатает — приложение само посылает запросы и показывает результаты. Смысл задания — отмена устаревшего ответа через `AbortController`, а не фильтр «показать последний пришедший».

`restcountries.com` в этом задании не используется.

## Стек

Можно и нужно:

- TypeScript для всей логики и UI;
- ESLint и Prettier, скрипты `lint`, `format`, `test`;
- Husky: **pre-commit** — только `lint-staged` (ESLint + Prettier на изменённые файлы), тесты не запускает; **pre-push** — `npm test` и не пускает красные тесты;
- компиляция `tsc` в ES-модули, подключение в `index.html` скриптом. Бандлер не обязателен;
- тесты на Jest или Vitest, с fake timers и моком `fetch`;
- свои `debounce`, обработка отмены и, если делать бонус, свой кэш.

Нельзя:

- lodash и другие библиотеки для debounce и кэша;
- отменять гонку флагом «показать только последний ответ» без `AbortController.abort()`;
- свой backend или прокси: `countries.dev` вызывается из браузера;
- писать реализацию обязательных функций раньше их тестов;
- `innerHTML` и `insertAdjacentHTML` для динамического контента.

`body` в `index.html` пустой, кроме тега скрипта. Логика запроса, отмены, маппинга и debounce не зависит от DOM и тестируется без браузера и без настоящей сети.

## Поведение

Обязательные функции:

- `debounce(fn, delay)` — откладывает вызов на `delay` мс; повторный вызов сбрасывает таймер. Задержку README не задаёт.
- `searchCountries(query, signal)` — `fetch` со строкой поиска и `AbortSignal`, промис с массивом стран. Проверяет `response.ok`: `fetch` сам не бросает на 4xx/5xx.
- `HttpError extends Error` — хранит статус. Бросается из `searchCountries`, когда `response.ok === false` и статус не означает «совпадений нет».
- 404 от `countries.dev` — пустой результат, не ошибка. Пример тела ошибки API: `{ "error": "Country not found" }`. Другой неуспешный статус, сеть, сервер и таймаут — ошибка пользователю, с кнопкой повтора.
- `mapCountryResponse(raw)` — чистая функция в данные карточки: название, флаг, столица, регион, население, языки. Тесты без сети, на заготовленных JSON.
- Отмена: при каждом изменении ввода, не только когда debounce уже запускает сеть, активный запрос отменяется через `AbortController.abort()`. `AbortError` в `catch` не показывается как ошибка.
- Таймаут — тоже ошибка. `AbortSignal.timeout(ms)` или `setTimeout` + `abort()`. В `catch`: `TimeoutError` и `AbortError` различаются. Один `signal` у `searchCountries` собирается так: `AbortSignal.any([signal, AbortSignal.timeout(ms)])`, либо ручная связка, если `AbortSignal.any` недоступен.

`GET /name/{query}` возвращает массив. В живом ответе на `/name/spain`: `name`, `capital` — строки; `region`, `population`, `area`, `borders`; `languages` и `currencies` — массивы объектов (`languages[]`: `iso639_1`, `name`; `currencies[]`: `code`, `name`, `symbol`); `flag` — эмодзи, отдельно `flags.png` и `flags.svg`. Поля описания страны в этом ответе нет.

Экран:

- поле ввода; пустой ввод — запрос не уходит, список очищается;
- пока запрос летит — индикатор загрузки;
- результаты — карточки: флаг, название, столица, регион, население;
- нет совпадений — дружелюбное «ничего не найдено», не похожее на ошибку;
- настоящая ошибка — сообщение и кнопка «Повторить»: повтор именно последнего введённого запроса;
- клик по карточке — детальный вид: описание, площадь, границы, языки, валюта.

Чек-лист для описания PR (проходится на деплое):

- пустой ввод — запросов нет, список пуст;
- во время запроса виден индикатор загрузки;
- быстрый набор не показывает результат устаревшего запроса;
- в Network отменённые запросы помечены `canceled` / `aborted`;
- отмена своего запроса не показывается как ошибка;
- 404 — «ничего не найдено», не ошибка;
- реальная ошибка (сеть в DevTools) — сообщение и «Повторить», повтор отправляет последний введённый запрос;
- клик по карточке открывает детальный вид.

## TDD и коммиты

Для `debounce`, `searchCountries`, `mapCountryResponse` и логики различения `AbortError` / `TimeoutError` / `HttpError` / 404:

1. отдельный коммит с падающими тестами по FIRST, раньше реализации;
2. отдельный коммит с реализацией, после которого тесты зелёные.

Потом отдельный коммит с тестом гонки: мок `fetch`, где промис более раннего запроса резолвится после более позднего; итог соответствует только последнему запросу. Мок обязан слушать `signal` и отклонять промис с `AbortError`, если `abort()` вызван до резолва.

Красный коммит один не запушить: pre-push гоняет `npm test`. Пара «красный + зелёный» уходит одним push. На первом коммите настройки пустой `npm test` должен проходить.

## DESIGN.md

Файл в корне репозитория:

1. как устроена отмена устаревших запросов и почему не флаг «актуальный ли ответ»;
2. почему выбрана задержка debounce и что будет, если её убрать или сильно увеличить;
3. Big O для `mapCountryResponse` и, если есть бонус, для кэша и дедупликации;
4. какие принципы чистого кода применены и в каком файле или функции.
