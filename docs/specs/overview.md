# Product & domain overview

## Что это

Живой поиск стран по имени. Пользователь печатает — приложение само запрашивает `GET https://countries.dev/name/{query}` и показывает результаты. Ключа и своего сервера нет.

Задача — отмена устаревшего ответа через `AbortController`. Ответ на более ранний ввод не должен заменить на экране уже пришедший ответ на более поздний.

## Правила

1. Пустой ввод запрос не отправляет и очищает список.
2. Пока запрос летит, виден индикатор загрузки.
3. Результаты — карточки: флаг, название, столица, регион, население.
4. Каждый новый символ сразу отменяет предыдущий активный запрос, не дожидаясь debounce.
5. `AbortError` этой отмены пользователю как ошибка не показывается.
6. 404 — дружелюбное «ничего не найдено», не похожее на ошибку.
7. Сеть, сервер, таймаут и прочий неуспешный статус, кроме 404, — сообщение об ошибке и кнопка «Повторить». Повтор отправляет последний введённый запрос.
8. Клик по карточке открывает детальный вид: площадь, границы, языки, валюта. Отдельного описания в ответе API нет, текст описания не показываем.
9. Быстрый набор не показывает результат устаревшего запроса. В Network отменённый запрос помечен `canceled` или `aborted`.

Контракт запроса: [search.md](./search.md). Экраны: [ui.md](./ui.md).

## Вне скоупа

- Свой backend, прокси, регистрация и ключ API.
- Библиотечный debounce и кэш.
- Бонус: кэш по строке запроса, дедупликация запроса в полёте, история в `localStorage`.
- Бандлер страницы.
- Submit в RS App.
