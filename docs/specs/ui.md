# UI

Решения: [D-004](../decisions.md). Состояние приходит из [search.md](./search.md), экран его только рисует.

Исходный `<body>` — только модульный скрипт. Узлы создаёт `el()`. Текст — `textContent`.

Фразы из README: «ничего не найдено», кнопка «Повторить». Сообщение настоящей ошибки — отдельная видимая фраза, не эти две. Точный текст ошибки фиксируется в коммите `feat/search-screen` и дописывается сюда.

Задержку debounce README не задаёт. В `feat/search-screen` константа `SEARCH_DELAY_MS` = 300. Сообщение настоящей ошибки: «Не удалось загрузить страны».

## `feat/app-shell`

Пустая страница собирает поле ввода, место индикатора, список, место сообщения и место детального вида. Запросов нет.

Проверка: после `npm run build` страница открывается со статического сервера. В исходном `body` по-прежнему только `script`. QA: `docs/qa/app-shell.md`.

## `feat/search-screen`

- Пустой ввод очищает список и не показывает загрузку.
- Непустой ввод показывает индикатор, пока сессия в загрузке.
- Успех рисует карточки: флаг, название, столица, регион, население. Картинка флага берётся из `flags.svg`, а если его нет — из `flags.png`. Поле `flag` остаётся эмодзи в данных карточки: на Windows оно рисуется буквами кода страны.
- Пустой результат рисует «ничего не найдено» и не выглядит как ошибка.
- Ошибка рисует своё сообщение и «Повторить». Кнопка снова запускает последний введённый текст.
- Состояния загрузки, пустого результата, ошибки и списка визуально различимы.

Проверка кликами и, для отмены, во вкладке Network. QA: `docs/qa/search-screen.md`.

## `feat/country-detail`

Клик по карточке показывает площадь, границы, языки и валюту этой страны из сохранённого сырого объекта. Поля описания нет — абзац описания не добавлять. Повторный клик по той же карточке не отправляет новый запрос.

Проверка кликами. QA: `docs/qa/country-detail.md`.

## Бонус: история

Под полем ввода строка «Недавние» и кнопки прошлых запросов. Они появляются после успешного поиска и после «ничего не найдено». Клик подставляет строку в поле и ищет её сразу, без ожидания debounce. Ошибка запрос в историю не пишет.
